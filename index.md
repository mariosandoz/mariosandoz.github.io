# Privacy Policy — Rekuro

**Terakhir diperbarui:** 4 Agustus 2026

Rekuro ("aplikasi ini") dikembangkan sebagai aplikasi pelacak langganan (subscription tracker) untuk membantu pengguna mengelola dan mengingat tanggal jatuh tempo langganan mereka. Kami sangat menghargai privasi Anda. Kebijakan privasi ini menjelaskan bagaimana data Anda diperlakukan saat menggunakan Rekuro.

## Ringkasan Singkat

Rekuro **tidak mengirim, menyimpan, atau membagikan data Anda ke server manapun**. Seluruh data yang Anda masukkan (nama langganan, harga, tanggal jatuh tempo, kategori, dan riwayat pembayaran) disimpan **sepenuhnya secara lokal** di perangkat Anda menggunakan penyimpanan lokal (Hive). Kami tidak memiliki akses ke data tersebut.

## Data yang Dikumpulkan

Rekuro **tidak mengumpulkan data pribadi apa pun** yang dikirim ke pihak pengembang atau pihak ketiga. Data yang Anda masukkan ke dalam aplikasi — seperti:

- Nama dan detail langganan
- Harga dan siklus penagihan
- Tanggal jatuh tempo dan riwayat pembayaran
- Kategori/tag yang Anda buat

— seluruhnya tersimpan **hanya di perangkat Anda sendiri**. Data ini tidak disinkronkan ke cloud, tidak dikirim ke server pengembang, dan tidak dibagikan ke pihak ketiga manapun.

## Analitik dan Pelacakan

Rekuro **tidak menggunakan layanan analitik pihak ketiga** (seperti Google Analytics, Firebase Analytics) dan **tidak menggunakan layanan pelaporan crash pihak ketiga** (seperti Firebase Crashlytics). Kami tidak melacak perilaku penggunaan Anda di dalam aplikasi.

## Izin Aplikasi

Rekuro dapat meminta izin perangkat tertentu (misalnya notifikasi) semata-mata untuk fungsi inti aplikasi, seperti mengingatkan Anda soal tanggal jatuh tempo langganan. Izin ini tidak digunakan untuk mengumpulkan atau mengirim data ke luar perangkat Anda.

## Pembelian Dalam Aplikasi (In-App Purchase)

Jika Anda melakukan pembelian fitur premium di dalam aplikasi, transaksi tersebut diproses sepenuhnya oleh **Google Play Billing**. Rekuro tidak menyimpan atau memiliki akses ke informasi pembayaran Anda (nomor kartu, rekening, dll). Status pembelian premium disimpan secara lokal di perangkat Anda untuk menentukan fitur mana yang terbuka.

## Ekspor dan Impor Data

Rekuro menyediakan fitur ekspor data (dalam format JSON) yang memungkinkan Anda menyimpan salinan data Anda sendiri, misalnya untuk keperluan cadangan (backup) atau berpindah perangkat. File hasil ekspor ini sepenuhnya berada dalam kendali Anda — Anda dapat menyimpannya, membagikannya, atau menghapusnya sesuai keinginan Anda sendiri. Pengembang tidak memiliki salinan atau akses terhadap file ekspor tersebut.

## Keamanan Data

Karena seluruh data disimpan secara lokal di perangkat Anda, keamanan data bergantung pada keamanan perangkat Anda sendiri (misalnya kunci layar, enkripsi perangkat). Kami menyarankan Anda menjaga keamanan perangkat Anda dan membuat cadangan data secara berkala menggunakan fitur ekspor yang tersedia di aplikasi.

## Perubahan pada Kebijakan Privasi Ini

Kebijakan privasi ini dapat diperbarui dari waktu ke waktu, misalnya jika aplikasi menambahkan fitur baru yang memengaruhi cara data ditangani. Perubahan akan dicerminkan melalui tanggal "Terakhir diperbarui" di bagian atas halaman ini.
